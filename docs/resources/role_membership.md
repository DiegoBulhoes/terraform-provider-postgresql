# Resource (postgresql_role_membership)

Makes `member` a member of `role`, as `GRANT role TO member`. Each resource manages one membership, so memberships can be added and removed without touching the roles themselves.

~> **Do not manage the same membership twice.** This resource and the `roles` attribute of `postgresql_user` must not both manage the membership of one user in one role: each would revoke what the other grants on every apply.

## Admin option

`admin_option = true` lets the member grant the role to others. Changing it runs `GRANT ... WITH ADMIN OPTION` or `REVOKE ADMIN OPTION FOR ...` and keeps the membership.

## Grantors (PostgreSQL 16+)

Since PostgreSQL 16 a membership has one row per grantor, and a plain `REVOKE` removes only the row granted by the current user. The provider handles each case as follows:

| Operation | Behaviour |
|-----------|-----------|
| Refresh | The membership exists while any grantor's row does; `admin_option` is true when any row has it |
| `admin_option` to false | Revokes the admin option once per grantor, in one transaction |
| Destroy | Revokes the membership once per grantor, `GRANTED BY` each, in one transaction |

A grant can be revoked only for a grantor whose privileges the provider's user has; a superuser has them all. Rows of other grantors are kept and reported in a warning, so the membership can outlive the destroy. Before PostgreSQL 16 there is one row and a plain `REVOKE` removes it.

## Drift detection

A membership revoked outside Terraform, or one whose role or member was dropped, is removed from state, and the next apply grants it again.

## Example Usage

```terraform
resource "postgresql_role" "readers" {
  name = "readers"
}

resource "postgresql_user" "analyst" {
  name = "analyst"
}

resource "postgresql_user" "team_lead" {
  name = "team_lead"
}

# Make analyst a member of readers
resource "postgresql_role_membership" "analyst_readers" {
  role   = postgresql_role.readers.name # Required: the role being granted
  member = postgresql_user.analyst.name # Required: the role receiving it
}

# A member that can grant the role to others
resource "postgresql_role_membership" "lead_readers" {
  role         = postgresql_role.readers.name
  member       = postgresql_user.team_lead.name
  admin_option = true # Optional, default false
}
```

## Import

Import a membership as `role/member`. The admin option is read from the server:

```shell
# role/member
terraform import postgresql_role_membership.analyst_readers "readers/analyst"
```
