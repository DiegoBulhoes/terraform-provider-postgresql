# Resource (postgresql_extension)

Manages a PostgreSQL extension.

The extension is installed in the database set in `database`, or in the provider's database when it is not set. Its files must already be on the server: `pg_available_extensions` lists the ones that are.

## Behavior details

- Create runs `CREATE EXTENSION`, with `WITH SCHEMA` and `VERSION` when `schema` and `version` are set. When they are not, the server picks them and the provider reads them back.
- `create_cascade = true` adds `CASCADE`, so the extensions this one requires are installed too. This resource does not manage them, and they stay installed on destroy.
- Changing `schema` runs `ALTER EXTENSION ... SET SCHEMA`. It works only for relocatable extensions.
- Changing `version` runs `ALTER EXTENSION ... UPDATE TO`. The server must ship an update path to that version; downgrades usually have none.
- When `schema` and `version` change together, both changes run in one transaction: if one fails, neither applies.
- Delete runs `DROP EXTENSION`, with `CASCADE` only when `drop_cascade = true`. Without it, an extension that other objects use is not dropped and the error says so.
- On refresh, the provider reads the schema and version from `pg_extension`. If the extension or its database is gone, the provider removes it from state.

## Example Usage

```terraform
# Minimal: only "name" is required
resource "postgresql_extension" "pgcrypto" {
  name = "pgcrypto" # Required
}

# Pinned version in its own schema
resource "postgresql_extension" "hstore" {
  name    = "hstore"                   # Required
  schema  = postgresql_schema.ext.name # Optional (defaults to the first schema in the search path)
  version = "1.8"                      # Optional (defaults to the control file's version)
}

# Install the extensions it requires (earthdistance needs cube)
resource "postgresql_extension" "earthdistance" {
  name           = "earthdistance" # Required
  create_cascade = true            # Optional, default: false
}

# Extension in a specific database, dropped with the objects that use it
resource "postgresql_extension" "citext" {
  name         = "citext"                           # Required
  database     = postgresql_database.analytics.name # Optional (defaults to provider database)
  drop_cascade = true                               # Optional, default: false
}
```

## Schema

### Required

- `name` (String) The name of the extension. Changing this forces a new resource.

### Optional

- `create_cascade` (Boolean) If true, create also installs the extensions this one requires (CREATE EXTENSION ... CASCADE). Default: false.
- `database` (String) The database to install the extension in. Defaults to the provider's configured database. Changing this forces a new resource.
- `drop_cascade` (Boolean) If true, destroy drops the extension with CASCADE, deleting every object that depends on it. Default: false.
- `schema` (String) The schema that holds the extension's objects. Defaults to the first schema in the search path. A change runs ALTER EXTENSION ... SET SCHEMA.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `version` (String) The version of the extension. Defaults to the version in the extension's control file. A change runs ALTER EXTENSION ... UPDATE TO.

## Import

Import an extension by its name, or as `database/extension_name`:

```shell
# Import by extension name
terraform import postgresql_extension.pgcrypto pgcrypto

# Import with database prefix
terraform import postgresql_extension.citext my_database/citext
```
