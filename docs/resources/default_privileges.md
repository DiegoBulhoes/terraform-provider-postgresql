# Resource (postgresql_default_privileges)

Manages `ALTER DEFAULT PRIVILEGES`: the privileges `role` gets on tables, sequences, functions, types or schemas that `owner` creates from now on. It does not touch objects that already exist; use `postgresql_grant` for those.

## Scope

| Setting | Applies to |
|---------|------------|
| `schema` set | Objects `owner` creates in that schema |
| `schema` unset | Objects `owner` creates in any schema of the database |
| `object_type = "schema"` | Schemas `owner` creates; `schema` must be unset |

Default privileges belong to one database: the one in `database`, or the provider's database when it is unset. The provider's user must be `owner`, a member of it, or a superuser.

## Valid privileges

The provider checks privilege names against the same allowlist as `postgresql_grant`, at plan time, before any SQL runs. Case does not matter; `ALL` stands for every privilege the server knows for the object type. The server rejects a keyword that does not fit the object type, such as `EXECUTE` on tables, and nothing changes.

## Drift detection

On refresh, the provider reads what `role` holds in `pg_default_acl` for the owner, schema and object type. A privilege revoked outside Terraform shows up as a change. `select` and `ALL` do not cause a diff when the server holds the same privileges.

PostgreSQL's built-in defaults (the owner holds everything; `PUBLIC` gets `EXECUTE` on functions and `USAGE` on types) are not rows in `pg_default_acl` and are not managed here.

## Example Usage

```terraform
# Tables app_owner creates later in the app schema are readable by app_reader
resource "postgresql_default_privileges" "reader_tables" {
  owner       = "app_owner"      # Required: the role that creates the objects
  role        = "app_reader"     # Required: the role that receives the privileges
  database    = "my_application" # Optional: defaults to the provider's database
  schema      = "app"            # Optional: without it, every schema
  object_type = "table"          # Required: table, sequence, function, type, or schema
  privileges  = ["SELECT"]       # Required
}

# Sequences, needed for INSERT with serial or identity columns
resource "postgresql_default_privileges" "writer_sequences" {
  owner       = "app_owner"
  role        = "app_writer"
  database    = "my_application"
  schema      = "app"
  object_type = "sequence"
  privileges  = ["USAGE", "SELECT"]
}

# Functions app_owner creates in any schema, with delegation
resource "postgresql_default_privileges" "functions" {
  owner             = "app_owner"
  role              = "app_admin"
  database          = "my_application"
  object_type       = "function"
  privileges        = ["EXECUTE"]
  with_grant_option = true # Optional, default: false
}

# Schemas app_owner creates later: object_type schema takes no schema
resource "postgresql_default_privileges" "schemas" {
  owner       = "app_owner"
  role        = "app_reader"
  database    = "my_application"
  object_type = "schema"
  privileges  = ["USAGE"]
}
```

## Schema

### Required

- `object_type` (String) The type of future objects: table, sequence, function, type, or schema. schema is allowed only without schema.
- `owner` (String) The role whose future objects get the privileges (ALTER DEFAULT PRIVILEGES FOR ROLE).
- `privileges` (Set of String) The privileges to grant (e.g. SELECT, INSERT, USAGE, EXECUTE). Case-insensitive; ALL stands for every privilege of the object type.
- `role` (String) The role that receives the privileges.

### Optional

- `database` (String) The database the default privileges are set in. Defaults to the provider's database.
- `schema` (String) The schema the default privileges apply in. Without it, they apply to objects the owner creates in any schema.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))
- `with_grant_option` (Boolean) Whether the role can grant the same privileges to others.

## Import

Import as `owner/role/object_type/database/schema`, or `owner/role/object_type/database` for defaults in every schema. An empty database part means the provider's database. The privileges are read from the server:

```shell
# Defaults in one schema: owner/role/object_type/database/schema
terraform import postgresql_default_privileges.reader_tables "app_owner/app_reader/table/my_application/app"

# Defaults in every schema: owner/role/object_type/database
terraform import postgresql_default_privileges.functions "app_owner/app_admin/function/my_application"
```
